# Reto Verbal

Videojuego educativo en un único archivo HTML para practicar los tiempos verbales del español.

## Cómo jugar

Abre `index.html` directamente en cualquier navegador. No necesita instalación, servidor ni conexión a Internet.

Incluye:

- Indicativo: presente, tiempos de pasado, futuro y condicional, simples y compuestos.
- Subjuntivo: presente, pasados y futuros, simples y compuestos.
- Imperativo.
- Verbos de las tres conjugaciones (`-ar`, `-er`, `-ir`).
- Verbos regulares, irregulares, pronominales, defectivos e impersonales.
- Puntuación, rachas, progreso, retroalimentación y selección de categorías.
